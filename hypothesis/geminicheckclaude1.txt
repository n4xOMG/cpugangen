## 3. Kiến trúc Đề xuất: "Look-up & Fallback"

Thay vì dùng Neural Network làm cốt lõi, ta dùng Hash Map làm cốt lõi.

### 3.1. The Dictionary (Hot Path - 95% traffic)
- **Cấu trúc:** Key-Value Store (Hash Map).
    - **Key:** Hash của Tag string (ví dụ: `hash("hatsune_miku")`).
    - **Value:** Vector embedding (768-dim hoặc 1024-dim).
- **Nguồn dữ liệu:** Sử dụng CLIP ViT-L/14 (Large) để encode trước toàn bộ 300.000 tags phổ biến nhất của Danbooru.
- **Tối ưu RAM (Critical):**
    - Raw: 300k tags * 768 dims * 4 bytes (float32) ≈ 921 MB (Quá lớn).
    - **Solution:** PCA reduction (xuống 512 dims) + Int8 Quantization.
    - Optimized: 300k * 512 * 1 byte ≈ **153 MB** (Rất nhẹ, load RAM cực nhanh).
